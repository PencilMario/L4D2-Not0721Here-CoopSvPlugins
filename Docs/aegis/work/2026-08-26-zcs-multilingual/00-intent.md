# Zombie Character Select 多语言支持：任务意图

**目标：** 让 `l4d2_zcs_redux` 的玩家可见提示和感染者限制 HUD 支持 `en`、`chi` 两种语言。

**范围：** 新增插件专用翻译资源；在插件启动时加载资源；将按键提示、限制/冷却提示、类别选择提示、锁定提示、HUD 标题、HUD 冷却标记和感染者类别名称接入翻译。单个玩家消息必须使用显式目标客户端的 `%T`。HUD 必须按每个玩家的语言分别生成。

**兼容性：** 保留现有 Tank 切换、`zcs_tank_limit`、`versus.cfg` 和六类普通特感限制逻辑；保留内部英文类别名用于调试日志和 `sm_buy` 参数匹配；不改变 ConVar 名称、默认值或类别选择顺序。

**非目标：** 不补齐其他语言，不重构无关插件，不改变游戏逻辑、颜色格式或 Tank 限制行为。
