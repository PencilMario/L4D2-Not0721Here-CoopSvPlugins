# Intent

Rename the survivor Bot anti-lag plugin and base its boost on map-flow progress. A Bot behind every living human gains 0.1 movement multiplier per full percentage point behind; invisibility multiplies the result by 1.25. More than 10% behind continuously grants adrenaline and enables shove-killing common infected until it catches up.

Compatibility: only living survivor Bots are modified; Witch, special infected, survivors, and unrelated entities must never be killed by the shove feature. Existing mode plugin lists must load the renamed SMX.
